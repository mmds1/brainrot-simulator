# Brainrot Fighter — Simulador de Lutas 3x3

Simulador das lutas do PvP do Brainrot Fighter (Roblox). Monte dois times de até 3 brainrots (Épico para cima), escolha
nível, estrelas, mutação, talento e artefatos, e veja quem ganha em centenas de lutas.

Roda inteiro no navegador: o motor de luta é o mesmo código Luau do jogo (`engine.luau`), executado pelo
[luau-web](https://github.com/xNasuni/luau-web) (licença MIT, em `vendor/luau-web/LICENSE`).

Este repositório só tem o site gerado. Não editar à mão: ele é montado a partir do jogo.
